Explore the school system

The problem

Schools run on paper, spreadsheets and WhatsApp. Results arrive late, fees are chased by hand and parents hear too little.

What we built

  • Report cards for every class and term
  • CBT exams taken on screen
  • Attendance for students and staff
  • Fees and payments
  • Live classes
  • SMS and messages to parents and staff
  • Timetables and subjects for each class level
  • School transport and library
  • Leave requests and staff records
  • Roles and permissions for every kind of user

How it is built

A Python and FastAPI backend, a PostgreSQL database and a Next.js and React front end, designed so every role gets its own view.
